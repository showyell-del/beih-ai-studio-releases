## Install

1. Download the DMG from the latest GitHub Release.
2. Open the DMG.
3. Drag `beihstudio.app` into `Applications`.
4. On first launch, if macOS blocks the unsigned app, use **System Settings → Privacy & Security → Open Anyway**.
